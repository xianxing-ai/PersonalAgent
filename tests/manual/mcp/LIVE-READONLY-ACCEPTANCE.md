# 远程 MCP 真实只读服务验收

目标：`huawei_ict_agentarts` / MOD-06。负责人：goo122。状态：未执行；本文件只准备验收入口。已有本机 TLS、Electron 和合成对话框证据见 [README](README.md)，不替代下列实际服务验证。

## 开始条件

- 使用经过检查的明确提交，记录完整 SHA、Desktop/Node 版本及 Windows 版本。按锁文件构建，使用独立验收 userData；`PA_USER_DATA_DIR` 必须是绝对目录，同一目录只运行一个 Desktop。保留正常退出后的数据库与配置用于重启验证。
- 确定获授权的 HTTPS MCP 服务、唯一只读工具、允许的公开测试参数和调用上限。连接握手/目录查询与 `tools/call` 分开计数。本清单正常路径最多一次 `tools/call`；失败时先核对服务记录，不自动重发。
- 准备已审查的服务定义 JSON，顶层恰为 `endpoint`、`server`、`tool`、`directoryDigest`。endpoint 不含用户名、密码、query 或 fragment；目录摘要用公开 `remoteMcpDirectoryDigest(tools)` 对获准取得的真实目录计算，并由受信人员核对。发现目录不等于批准目录。
- `server` 固定 name/version；`tool` 固定 remoteName 与 descriptor（name/version/inputSchema/outputSchema/requiredScopes）。本地名称以 `mcp.remote.` 开头；输入/输出为对象 Schema。结构依据 [Desktop 配置说明](../../../apps/desktop/README.md)，禁止在定义文件中加入 token。
- 如服务需要凭据，使用用户已授权的短期 token，仅在原生管理窗口填写；到期时间为规范 UTC ISO 字符串。当前支持已有 bearer token，不具备 OAuth 登录、刷新或服务端撤销流程。
- 使用 Competition 正式管理后台，确认 Runtime 已就绪。缺配置时记录具体不可用状态；不启用 Fake 模式来代替真实验收。若补齐 Runtime 需要新的真实账号或云操作，先完成相应授权，再继续。
- 准备服务侧可核对的脱敏请求计数或回执。若只能看到本地 UI，外部读回一栏记录“未验证”。本轮不向模型发送 MCP 结果，不发起 AgentArts 任务。

## 按界面逐步执行

从正式管理后台打开「远程 MCP 管理」。表中“工具次数”仅指 `tools/call`；握手、目录核对等网络访问另行记录。所有确认使用实际原生窗口；自动注入对话框回答的运行只能归为合成验证。

| 步骤 | 操作 | 必须观察到的行为 | 证据 |
| --- | --- | --- | --- |
| 1 配置 | 「导入服务定义」，输入获准 token/到期时间，点击「确认并加密保存」并核对原生提示 | 保存不联网、不授予执行权限；提示需重启 | 脱敏配置摘要、状态；不截 token 输入框 |
| 2 重启 | 正常退出，再以相同独立 userData 启动 | 配置可读回，默认断开；本次会话尚未获准连接 | 前后状态和服务工具计数 0 |
| 3 连接 | 「确认连接」，核对 HTTPS 地址、服务/工具版本及目录摘要 | 实际 TLS/身份/目录核对成功；工具计数仍为 0 | 原生提示、连接状态、服务端握手回执 |
| 4 拒绝 | 填入获准业务参数，点「创建审批任务」，保存原任务 ID；点「拒绝」 | 请求先进入 waiting_approval；拒绝后无工具调用 | 原任务状态、工具计数 0 |
| 5 批准一次 | 创建新任务，保存 ID，点「原生确认并批准一次」，核对原任务/工具/参数 | 批准前工具计数 0；批准后最多 1；必须读回终态及执行记录 | taskId、终态、执行回执/Evidence 引用、服务计数 1 |
| 6 结果读回 | 使用同一 ID 点「读回原任务」；然后「断开」并再次读回 | 已确认结果可读回；不增加工具调用 | 两次读回状态、服务计数不变 |
| 7 旧许可 | 重新确认连接，创建另一个审批任务但不批准；记下 ID，正常退出并重启 | 新会话默认断开；旧待审批任务不能凭旧连接/绑定再次调用；允许安全拒绝、过期或待核实，不要求伪造成功终态 | 旧 taskId、实际拒绝/终态、服务计数不变 |
| 8 重启读回 | 读回步骤 5 已完成的原任务 | 保留原终态与回执，无重新执行 | 原任务引用、服务计数不变 |
| 9 本机撤销 | 「撤销并清除本机配置」，按实际原生提示确认 | 配置禁用，连接不可继续；若显示 revoke_pending，则清除未完成 | 状态、仅记录配置文件是否存在，禁止输出文件内容 |
| 10 撤销后重启 | 正常退出重启，再刷新管理状态 | 配置不可复用；旧任务历史可保留，不能恢复执行许可 | 状态和服务计数不变 |

步骤 5 若进入 waiting_reconciliation、出现超时或结果未知，停止后续调用，核对服务计数和 Runtime 原任务；保存失败证据。本机撤销不等于服务端 token 撤销；后者需要单独授权和独立回执。本清单不删除历史任务或数据库来制造撤销成功。

## 分开保留的验收范围

不受信证书、主机名不符、目录漂移、重定向，以及长驻 130 次调用/旧 run 防重放，继续使用 [本机合成入口](README.md) 和根 `tests/integration/remote-mcp-capacity*.test.mjs`。不为了覆盖这些负例修改真实服务或额外消耗真实调用额度。真实服务结果不能自动提升 OAuth、任意写工具、云端工具编排、跨进程并发配置或整个 MOD-06 的状态。
