# 0040 渐进式云端开发执行与按需工具发现

状态：implementation，2026-10-24。Profile：`huawei_ict_agentarts`。最终组合验收进行中。

## 问题与方案

当前默认对话的思考偏好会把组合入口的步骤预算覆盖为 2～12 步；完整工具目录超过 64 项时，在发出第一次云请求前直接失败。连续回执全部携带，又会在超过 32 条历史回执或传输大小限制时失败。这些限制不能用提高单次输出 token 一个数值解决。

新任务可由可信宿主明确启用渐进执行窗口。原 Runtime 保留完整任务、工具结果及检查点，在已有确认进展且没有未知操作时继续下一窗口；重复同一输入、取消、期限及用户明确预算仍能停止执行。旧任务沿用原持久策略，不追补扩大旧授权或期限。思考深度与执行容量分离。

工具目录仍服从现有镜像的每次 64 项／24 KiB 限制。启用按需发现后，宿主在原任务中冻结当时可用工具的精确名称、版本和公开 Schema；目录较大时先公布只读 `capability.search`。该工具分页检索这个原始集合，声明总数和后续页。只有原 Runtime 已确认的检索结果可以切换下一轮的工具页；目录切页不是执行授权，仍由原 Policy／ToolGateway 执行目标工具。不得使用静默截断、任意通用调用器或新注册能力扩充原任务。

后续每次提案及实际发送前继续核对原目录、当前 readiness、Schema、任务和期限。能力变更、撤销、跨任务游标及未经确认的发现结果不能激活工具。根级说明只允许可信组合显式发布的有界说明，外部任意描述不因此成为系统指令。

连续执行只发送当前回执和有界近期回执，明确公布省略数量及不含正文的进度元数据。完整回执仍在原 Runtime，必要源码及状态经原有工具重新读取；摘要、计数和模型文字不替代原执行证据。保留实际发送窗口中的逐项来源及出机重验，不把旧私人正文复制进无界摘要。

省略旧回执不释放旧提案 ID。宿主的瞬时环境说明为每次新请求提供随机唯一的 `nextProposalId` 建议，并说明旧 ID 换参会被拒绝、相同提案仅重放原确认结果；不重写模型提案或放宽原冲突规则。

目录读取的原生提问卡使用新的 `workspace-relative-directory-v1` 投影，明确列出将出机的相对目录、直接条目名称和类型。没有该原操作的出机决定不能发送条目；旧概括 consent 仍只返回原脱敏布尔元数据。提案中的完整路径、文件正文和其他目录不在目录投影范围内。新投影版本会使旧回执按既有导出策略变更门禁处理，不自动升级旧授权。

默认任务的父汇总只能在原必需 user-work 子任务成功后完成。子任务失败或取消时，即使云端返回成功措辞，父任务也拒绝成功提交，保留原子任务及已确认效果；不重新派遣或重做写入。

WSS 宿主可显式启用 `recoverAcceptedStatus:true`。仅在原 accepted 回执已持久、原连接仍活跃且 ready 声明支持 status 时，间隔 30 秒查询同一身份；每读最多 10 秒、不越过原期限、最多一读，凭据重新读取。只有原四字段与服务实例完全匹配的合法终态才能走原终态结算、原解析与持久校验。读失败、unknown、实例变化均不推断执行结果，原调用继续等待；已取消、断连、关闭或超期的调用不能由迟到查询复活，不重发 invoke。

最终出机校验使用仅存活于一次同步调用的 Runtime 不透明读作用域。原 `competition-loop` 只解码一次并递归冻结；每次访问和作用域返回前仍从 SQLite 读取并严格比较原始 JSON 字节。另一个连接或本连接改变原文均拒绝，不缓存授权、readiness、撤销、期限或私人数据状态。普通 `loadCheckpoint()` 仍返回独立副本；跨任务、跨 Runtime、伪造、异步或过期作用域不能读取。未引入跨请求缓存、第二份回执日志或新迁移。

## 兼容与验证

不修改冻结 Core wire，不增加第二套任务、权限、调度或连接器注册表。新发现工具和执行策略为 host-only 可选增量，Desktop 默认组合显式启用；未启用的调用方及旧检查点行为不变。既有镜像可消费原格式的有界目录和回执。

修改单次输出、上下文或传输容量时，必须同时核对真实模型能力、本地 adapter、镜像 parser 和部署版本；不能仅修改本机常量后宣称云端已扩容。大型项目采用多阶段和增量文件操作，不能以单次超长回答替代实际修改、检查与读回。

验收覆盖超 64 工具／大 Schema 分页、页切换后的真实 Runtime 执行、撤销／变更／跨任务／取消反例、超过 32 轮的持续执行与旧策略兼容。真实云、当前镜像和新平台部署分别记账。

第五轮完整 `npm run check` 已取得 exit 0（6,027 pass／29 skip／0 fail），包含当前原生 Node 绑定、最终校验作用域、父子完成事实和已受理 WSS 状态恢复。125 项最新聚焦及 72 次隔离文件动作分别保留证据；协调器／socket 为明确合成实现。真实默认桌面修复已通过，真实多文件超窗验收单独记录。完整证据与限制在[实施记录](../competition/PROGRESSIVE_EXECUTION_20261024.md)维护。
