# ADR-0038：批次导入和可追溯 LLM Wiki

- 状态：proposed；隔离 AgentArts 真实模型、桌面合成数据与单次会话内自动维护已验证；平台评估、长期运行和正式部署仍待验证。见 [云端验收记录](../competition/evidence/wiki-cloud-acceptance-20261028.md)。
- 日期：2026-10-27
- 目标 Profile：`huawei_ict_agentarts`。

## 决策

桌面可信宿主记录用户通过本机选择器选定的来源身份、版本和库目录，Renderer 仅接收不透明标识与展示元数据。库中已有来源与本次新增来源共同进入批次清单，用户授权覆盖同一清单、目的库、固定的 AgentArts 版本和预算。源文件不被修改，解析后的内容由知识模块编译成有证据引用的 Markdown 页面。

`knowledge.compile_wiki` 和 `knowledge.ask_wiki` 是 Runtime 组合根注册的 host-only 工具，沿用 TaskRuntime、Policy、ToolGateway 及原有授权问题。任务摘要只保存标识、哈希、数量和执行回执，来源正文与生成结果保存在用户选择的本地知识库。问答生成内容在进程内返回桌面，任务回执不保存答复正文；用户的问题按现有 Runtime 任务参数保留。模型请求数据被标识为不可信材料，AgentArts 工作流经 ModelGateway 调用配置模型，不取得本地路径、凭据、工具或权限。

文件解析在受限 worker 中执行；PDF、Office、HTML、CSV、图片和本机中英文 OCR 的覆盖状态逐项记录。无法读出、低置信度及无法解释的图片/图形保持待处理状态，不宣称完整。

Wiki 库使用独立于 Runtime 任务状态的领域存储：原文快照、解析单位、页面与版本索引。一次生成先写入不可变 generation，读回页面哈希后使用 SQLite 事务切换当前指针；文件系统和数据库不是一个原子事务。中断后只核实原运行回执，不盲目重发模型或重写文件。已撤销、改变或无法核对的来源不能被查询、问答或回滚重新消费。

生成 Wiki 不自动创建确认的私人长期事实。写入和读取授权、云端发送、用户确认的长期记忆是不同边界。现有知识数据库与 Markdown 文本不具备整库加密；桌面选择目录配置使用现有安全存储，来源内容不写入普通任务记录或日志。

## 契约与兼容

新增 `@personal-agent/contracts/wiki-workflow` provisional 协议，通过现有受认证 AgentArts `/invocations` 传输；`wikiVersion: 1` 支持知识提取、归类和问答。服务端只调用现有 ModelGateway，校验输入身份，返回标注 `unverified` 的结果。调用方校验结构和来源引用；引用定位可验证，语义真实性仍需评测。尚未更新的云端镜像对该服务明确返回 unavailable，不静默回退。

该能力使用固定的部署版本以绑定批次和缓存。已有聊天、知识源和压缩任务接口保持现有行为，未迁移用户数据。新库 SQLite 从版本 1 建立；不修改既有 Runtime 或记忆数据库迁移。启用 OCR 会增加应用依赖及安装体积。

## 恢复与限制

每次模型请求先记录唯一标识和预算预留；已发送但结果未知不自动重发。写入之前记录发布意图，成功切换后的结果可读回原 generation 并恢复；缺少证据则继续显示待核实。重启后的授权按现有机制重新取得，终态任务不重开。

若用户在导入时启用自动维护，原任务在同一授权会话内跟踪该批绑定的来源身份，仅在截止时间和总预算内处理这些文件的新内容；新增来源和文件身份替换须重新授权。停止维护后结束原任务，重启不得恢复旧会话授权。真实模型下的单文件变更已用合成数据验证；多文件、长期稳定性及内容质量仍需进一步评测。
