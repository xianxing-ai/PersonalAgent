## 决定与兼容性

在 Runtime Application 增加 host-only 来源监视入口，由 Desktop 现有定时入口驱动，
不创建另一套任务库、调度器、模型入口或持久正文索引。启用所选知识源后每 30 秒最多
启动一次只读检查；同实例不并发检查，关闭取消在途操作。切库和撤销仍由原来源 lease
即时阻止读取及投影。

监视仅保留本进程页面 ID、路径和正文 revision 的目录快照。首次检查或重启时校验
当前来源绑定的既有确认记忆；之后只检查变化及旧位置。每次都使用新的受信读取 lease。
只有成功扫描和投影完成后才推进目录快照，失败保留待核实状态，之后重试只读检查。
临时缺失、空目录、扫描失败不证明删除，不删除正文、事实历史或备份。

Memory 继续使用原 SQLite 版本和来源失效事务。变化只撤回旧确认事实，不把新笔记
自动保存成长期记忆，也不自动绑定私人 Feed/Goal。局部投影后失败可重复检查，事务
幂等避免重复撤回。UI 只显示检查状态、页面数及时间，不暴露原始异常或新增出机内容。

公开进程内端口保持 provisional；无 wire capability、数据库迁移或新依赖。历史
调用方不装配监视器时行为不变。完整全文索引、Obsidian 插件、私人备份删除协调和
真实 AgentArts 验收属于后续范围；本次只用独立公开合成文件验收。
