# ADR-0037：对话上下文输入上限提高至 128,000 字符

- 日期：2026-10-22
- 状态：accepted（用户明确选择 128,000 字符；真实云端部署另行验收）
- Profile：`huawei_ict_agentarts`

## 决策

任务、准备输入与历史消息编译后的总输入上限从 16,000 提高为 128,000 UTF-16 单元。Runtime、Coordination 与自有 AgentArts 输入解析使用 contracts 中同一常量；初始带工具目录请求的 UTF-8 预算同步扩大到已有云入口的 1,100,000 字节预算。Desktop 的 Skill、Live 历史、委派请求和摘要策略预检同步接受新边界。

超限仍拒绝；普通对话原有的用户请求保留规则、撤回/来源校验、摘要确认及模型 token 预算门禁继续生效。模型原生窗口及精确 tokenizer 未因此得到验证。模型回复、工具结果、业务投影、网络帧和输出 token 预算不随上下文扩容改变。

桌面子任务汇总中的宿主 `userRequest` 承载编译后的会话输入，使用相同 128000 上限；子任务回答投影继续单独受 64 KiB 约束，整份续轮仍受原有传输和 JSON 预算约束。

## 兼容与迁移

不新增 wire 字段、数据库迁移、依赖或另一套上下文存储。旧配置中较小的显式摘要预算继续有效，不自动启用摘要或发送旧私人内容。已有任务的上下文检查点绑定了预算；跨版本恢复若预算不同，继续拒绝漂移，需新建任务，不能重做待核实的原操作。

本地与自有云镜像的输入校验需要配套更新；本机源代码及合成链路通过不代表已发布的云镜像接受 128,000 字符。部署状态、真实模型窗口和本机代码验证分别记录。

2026-10-22 用户另行授权发布，已部署 `arm64-context-128k-1022` 并完成公开合成历史的真实云端复验；实际最大编译输入 125739 字符，三条主任务完成，详见[验收记录](../competition/CONTEXT_LIMIT_128K_20261022.md)。
