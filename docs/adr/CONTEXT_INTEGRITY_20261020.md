# 会话上下文完整性修缮（2026-10-20，实施中）

目标 profile 为 huawei_ict_agentarts。复用 Runtime 任务/事件、Desktop 会话存储、原发送绑定和工具导出门禁，不另建任务库、模型入口或授权体系。

1. 历史按当前任务创建事件截面读取，保留失败、取消和未完成任务的用户原文；执行状态不代表需求已回答。私人/删除/撤销过滤继续优先。
2. 取消固定20条的静默裁剪。共享编译器在普通对话中优先保留全部用户原文及当前目标；超预算时只省略助手历史并披露来源清单。Skill、私人消费及确认预检保持严格完整预算。用户原文仍超预算则明确拒绝，不伪造语义摘要。需求状态首先采用可重建的原文时间线，更新/否定由带来源的原文表达，不用关键词猜测用户目标；同会话原文工具仅按既有引用取回仍可读的来源，不转移原私人消费许可。
3. 工具续接可由受信组合显式启用 goal 投影；默认旧 JSON 保持兼容。复用已绑定的编译目标，不从工具结果采信原问题；控制面部署兼容后才启用。
4. 长子任务正文不再静默截断；超出既有导出上限明确拒绝并保留本地原始结果。上下文选择清单只持久化摘要、身份散列与预算，不保存额外私人正文。
5. 不自动新增长期记忆。重启从现有持久记录重建；撤销/删除后重新校验，不自动恢复私有消费授权或重放写入。

兼容性：不修改冻结 Core wire、旧迁移或原任务终态；新增受信内部调用选项默认关闭。回退可停用新续接选项，原数据继续保留。有限上下文不能无条件容纳无限信息，超预算必须可观察并阻止不完整答复。确切 tokenizer 未注入时继续标记 unmeasured，不把字符预算冒充完整模型 token 预算。

验收按保存、实际发送、最终答复分层：长对话/更正/未完成需求/失败恢复/工具续接/子任务/重启/隔离/删除；Fake 验证传递与权限，真实 AgentArts 另行验收。模型自查或覆盖声明不构成完整性证明。
