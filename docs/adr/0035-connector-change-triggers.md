# 0035 连接器变化触发主对话的本地提醒判断

状态：proposed，2026-10-21。Profile：`huawei_ict_agentarts`。

用户要求新邮件、天气明显变化等连接器事件进入主对话，由现有 Laya 判断是否告知用户。
来源变化本身不授予业务写权限，也不直接触发系统通知。

复用 TaskRuntime 的确认执行记录、结果缓存及原 host-state CAS 保存来源基线和待判断事件。
Desktop 只从原 Runtime 读回确认结果；不接受 Renderer 或模型提供的“变化已经发生”证明。
邮件首次完整同步及 UIDVALIDITY 改变只建立基线；天气比较同地点、日期、单位的公开预报，
不把缓存时间变化或陈旧回退当作天气变化。邮件正文不复制到提醒状态或云端。

由同一个本地 Laya 端口选择提醒、暂缓或忽略。决定写入原 Runtime 后才交给既有通知宿主，
继续受静默、额度、渠道和真实投递回执约束。通知未知只核实同一轮，不重发。
主对话仅展示选为提醒的原 Runtime 判断任务，忽略事件不会增加可见对话。

持续读取是独立、可审批的 `connector.watch.*` 工具操作，绑定原指令、准确查询、间隔、
期限和来源配置。复用原 Scheduler 与 ToolGateway；重启不恢复私人邮箱读取许可，
不因曾查询天气而偷偷建立订阅。只读轮询不宣称远端推送。

无数据库迁移或新增依赖，无 Competition 到 Local Agent 回退。Laya 仍只是本地有界判断端口，
不是新的模型执行入口或权限来源。真实邮箱、持续天气与真实模型验收分别记账；
本 ADR 不把缺少适配器的来源宣布为可用。
