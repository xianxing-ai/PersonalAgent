    • 键盘与读屏：任务行是真实 button、抽屉 Esc 可关、toast 走 aria-live polite、开关是原生 checkbox 语义、无 alert/confirm。

    设计理念

    野拓把工作区当作一块城市告示板：所有 Runtime 状态都不许藏在毛玻璃后面，一律钉在纸面上。3px 纯黑描边与无模糊硬影构成唯一的「材质」——没有渐变、没有 blur、也没有装饰性圆角，视觉成本全部让给信息本身。柠檬黄承担「进行」，信号绿承担「完成」，番红承担「警报」，三块高饱和色在纸底上划分出任务、审批与连接器三个街区；44px 以上的 900 字重标题是街区的路牌，加宽字距的小写标签是门牌。设置页回到「班签与登记表」的组织方式：一行一件事、左右分栏、按过就记住。部件的个性来自按压与贴纸：按钮按下时真的沉到阴影里，标注像便签一样斜钉在版面边缘，状态点用硬切闪动代替呼吸灯。

    动效基调80/150/240/400ms + 柔和缓动 cubic-bezier(.2,0,0,1)；data-calm 降级（≤150ms）。90ms 位移 + steps(1) 硬切闪点；按压是「位移到阴影里」的物理隐喻；reduced-motion 全停，且 ticker 由 JS 复次校验。
    桌面协同orb/panel/admin/workspace 四窗共享 desktop:update 快照；语言主题经 desktop:preferences 同步。快照模型、四窗拓扑、断点（960/900/720/640）全部不动；只是连接器面板改「行块信号板」，点击行为仍指向 admin 连接页。
    风险与取舍语义成熟、障碍小；但毛玻璃在分数 DPI 与低端 GPU 上有性能成本，双色叙事互相干扰。强对比与 900 字重长时间注视有压迫感，需备「纸 2 号」的降饱和衍生档（黑边不动、只压色）；3px 边框在 640px 断点占宽度，已在贴纸档位预留缓冲。
