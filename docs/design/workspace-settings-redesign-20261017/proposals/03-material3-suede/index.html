    无障碍说明

    • 对比度：正文 #1D1B20 / surface #FDF7FE ≈ 15.9:1；on-surface-variant ≈ 7:1；primary 文字 / 白 ≈ 6.4:1；on-primary-container / primary-container ≈ 11.8:1；error 文字 / 白 ≈ 5.1:1。全部满足 4.5:1 正文与 3:1 大字门槛。
    • focus 可见性：全局 :focus-visible 双环（surface 内环 + primary 外环）；键盘 Tab 遍历顺序与视觉一致，抽屉/对话框 Esc 可关闭。
    • 触达目标：交互控件 ≥ 40px，主要磁贴/行 ≥ 48px（M3 可及性基线）。
    • reduced-motion：媒体查询全局停用动画；模拟进度 accord 以 reducedMotion 状态判定。
    • 中英对照：新增词条按 desktop-shell.js 词典约定提供英文对照建议（如 磁贴 = tile / 连接器 = connector）。

    设计理念

    雪绒 · M3 以 Material 3 动态色彩为骨架：层级主要交给 tonal surface——雾面 #FDF7FE 底上铺开 surface-container 阶与 28px 超大圆角磁贴，浮起只保留极柔和的 elevation 1–3，不再依赖暗色阴影堆叠。三色角色做了明确分工：primary 靛紫承担主操作与 assistant 气泡，secondary-container 雾紫是选中态与控件容器，tertiary-container 等色面用来给目标/控件/连接器/任务四类磁贴做 color-coded 语言，让「哪块是主操作」一眼可读。深浅主题来自同一 seed 的 tonal 映射，语义色只在审批（error-container 顶 banner）与状态徽章出场。中文正文保持雅黑栈，任务/审批/目标文案沿用现行金标准；悬浮球保持现状，面板仍以球为锚点展开。

    参考体系与借鉴点

    • Material Design 3（Google）：三角色 token、tonal 容器层级、state layer hover、字阶命名、exposed dropdown menu、navigation rail、segmented buttons、FAB。
    • M3 动态色彩：seed 色生成 tonal ramp，明暗主题共用角色名（本页以 #6750A4 为 seed 演示）。
    • 现行「墨核」桌面：功能清单、任务状态词库、Evidence 文化（mock / conditional / verified）、克制的中文物案语气全量保留。
    • 设置页语法：分组导航 + 列表行，视觉容器换为 M3 list row + 暖中性 divider，分组习惯借鉴 Fluent / Carbon 后台经验。

    对比现行「墨核」玻璃方案

    逐维对比 + 悬浮球承接说明 + 落地建议。现行叙事（冷光青玻璃 vs 黑白纯面）两套并存，本提案一并给出裁决建议。

    维度现行墨核雪绒 · M3（本方案）
    明暗深色为主（bg #0b0d10 / #0e1116），深浅由 pa-theme 切换，admin/workspace 实心降级浅雾 #FDF7FE 为主，同一 seed 的深色作动态色副主题；明暗由 M3 tonal 角色统一接管
    材质玻璃 blur(42px) saturate(1.8) + 内高光；但 admin/workspace 已降级为实心 surface，黑白纯面覆盖层并存不透明 tonal 色面（surface / surface-container 分层），不使用毛玻璃；data-glass 置空可用，黑白覆盖层建议移除
    色板焦点accent #52c7bd 冷光青 + 主题变体（amber/vermilion/lime）M3 三角色暖靛紫 #6750A4 系 + #E8DEF8 / #FFD8E4 容器色 + error-container #F9DEDC 审批横幅
    字体Segoe UI Variable + 雅黑栈；11–34 字阶，标题 600 负字距中文正文雅黑栈不变；字阶改用 M3 命名（display-large 36 / headline-medium 24/600 / title-medium 16/500 / body-medium 14/400 / label-large 14/500）
    密度表格式密排（4–20px 圆角），断点 960/900/720/640 降密磁贴网格加大呼吸感（28px 圆角、48px 行高、20/24px 间距），小断点折叠为单列，密度换可扫读性
    导航形态侧栏 196/228px 链接列表 + 玻璃顶栏三窗口钮M3 navigation rail：icon+label，选中态 secondary-container 圆角药丸，带「搜索设置…」过滤与未入导航页脚
    交互中心对话面板 composer + workspace-layout 三列（chat / connector-board / inspector）磁贴 dashboard（目标/控件/连接器/今日任务）+ FAB「新任务」+ segmented 今日/本周/全部 + 状态 chip 行过滤
    动效基调80/150/240/400ms + cubic-bezier(.2,0,0,1)，data-calm 全停 ≤150ms 过渡150/250/300ms + emphasized 缓动；浮起靠阴影分级（e1→e3）+ hover 抬升；reduced-motion 与 data-calm 约定保留
    桌面协同orb / panel / admin / workspace 四窗一次 publish 同步 snapshot；无边框圆角窗 panel 20 / admin 12同步协议不变；窗口圆角建议窗体色统一走 M3 surface-token（panel/workspace 28 档、对话框 32 档），位置策略仍以 main.js / placement.js 为准
    风险与取舍成熟、密；但两套视觉叙事并存、admin 实心与玻璃语言割裂，浅紫等高饱和容器色缺席风险：控件断言族需随 switch/menu 结构变化适配、磁贴在大密度任务表下扫描路径变长；取舍：颜色语义更明确、明暗一致、审批警示更醒目

    悬浮球承接说明

    悬浮球继续保持现行设计：112×112 逻辑尺寸、右下角、hover ≤90px 触发展开、canvas 粒子球与呼吸动画一律不动。面板仍以球为锚点展开——右缘 +8px 优先停靠，放不下时移至球左侧；拖动时球与面板成组移动；Esc 收起面板。雪绒 · M3 只更换面板表面材质（不透明 tonal 色面 + 大圆角），不触碰 apps/desktop 的 orb 相关文件与 dock/展开判定，Windows 分数 DPI 场景仍按 placement.js 约定做 1×–2× 复测。

    落地建议（若采纳）

    • tokens.css：新增 data-scheme="m3-suede" 色板通道，映射本文档三角色 / 语义色 / 圆角 / 阴影 token；保留 data-theme / data-calm 约定，data-glass 在该通道置空。
    • style.css / surfaces.css：卡片、磁贴、列表行、表单控件换为 28 起步的大圆角与暖中性描边；admin/workspace 维持实心 surface，移除黑白纯面覆盖层（裁决：单一 M3 叙事）。
    • workspace-controls.js / admin view：switch / slider / exposed menu / segmented / FAB 控件结构变化需复查控件高度程序化断言族（busy / disabled 矩阵、防重复提交）。
    • desktop-shell.js：补齐新文案中英词典（磁贴/连接器/持续目标 等）；desktop-settings 字号缩放沿用 90–130% 通道。
    • electron/main.js：panel / admin / workspace 窗体圆角与背景色切至新 token；orb 窗口与放置逻辑零改动。
