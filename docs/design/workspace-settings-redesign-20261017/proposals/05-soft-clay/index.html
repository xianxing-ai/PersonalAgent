    私人助理 · Windows / 雾霭软陶 / 圆润黏土（提案预览 · 现行「冷光青」对照）

    设计理念雾霭 · 软陶

    一个每天替你收信、记事、盯日程的助理，应该先是个温柔的同伴，再是个止损的机器。现行「墨核」用深色玻璃回答专业；雾霭·软陶把答案换成清晨的托盘：浅雾对角渐变、超大圆角、软陶三层阴影，让每张卡都带着可以被托住的分量。交互以「帮你听着」语音陪伴气泡为中心，它先于打字框存在，像同伴侧过头来。红线不动：不重画悬浮球，欢迎块只放占位圆环并标注保持现状；功能词、审批语、连接器脚注全部沿用金标准——形象是新的，承诺是旧的。装饰色不进正文对比度，正文深紫墨对卡面 ≈12.1:1。

    取舍声明：浅色塑料感不等于低可用——语义警示用深珊瑚 #EF7B5F 与浅珊瑚底保证 4.5:1 以上；「跟随系统」保留深色示意态（token 翻转而非重设计）；data-glass / data-theme / data-calm 三属性约定保留，只是玻璃档位在本皮肤下视觉差趋近于零。

    参考体系与借鉴点
    • · HeroUI（原 NextUI，50k+ ★）：柔色 token 组织、「浅底 × 墨字」的按钮/容器配比。
    • · Claymorphism（社区流派）：内高光 + 内下阴影 + 大扩散投影的三层组合，全站统一韵律。
    • · Material 3：tonal container 思路（雾紫/薄荷各两阶 tint）、分段控件选中态。
    • · 漫游日记式排版：三列「目标 → 今日 → 快卡」纵向流动，任务像日记而非砖墙。
    • · 现行桌面字体族（Segoe UI Variable / Microsoft YaHei UI）：沿用，避免中文渲染成本与字重回退。
