设计理念 约 300 字

工控 · 磷光假设 PersonalAgent 的核心资产是「证据」而非对话。任务、审批、连接器健康因此全部以可打印的等宽文本出现：状态不用图形隐喻，而用 [RUN]、[WAIT]、[DONE]、[FAIL] 的字符标记直接陈述，附中文状态词，供核验、复制与审计。纯黑底与磷光单色模仿持久面对屏幕的操作员环境——降低对比噪声、让截图融入机房暗墙；琥珀与红只出现在需要人接管的时刻（授权请求、失败），成为真正的事件而非装饰。命令面板是唯一的入口假设：记住一个 Ctrl+K，等于记住整套系统。切角面板与黄黑警戒斜纹取自工业安全规范，只承担一件事：标记「此处有权重」。配置视图被表达成 config 文件，是因为设置应当像系统文件一样被逐条阅读和修订，而不是像橱窗一样陈列。

两套主题叙事的裁决 盘点 §3 残留问题

现行库存在两套叙事：tokens.css 的「墨核·冷光青玻璃」与 app/surfaces.css 顶部覆盖的「黑白纯面」（bg #101010、accent #ededed）。实际渲染里 admin/workspace 早已是黑白纯面卡片，只残留青绿点缀。本方案的裁决：承认黑白纯面为事实的 admin/workspace 语言，把它的「黑白」升级为「黑+磷光绿」，青绿强调色 #52c7bd 归位为发光描边的母色而不与磷光绿争夺焦点。data-glass / data-theme / data-calm 三个全局属性约定完整保留，本方案不删除任何一条主题约定，只在 admin/workspace 表面新增 CRT 覆层；panel/orb 的毛玻璃维持现状（球体不改）。

悬浮球承接说明 球体 · 不改一行

球体本体（112×112 逻辑尺寸、canvas 粒子、呼吸动画、hover ≤ 90px 触发展开）全部为现行设计，本方案零改动、零新增动画。本提案页在世界区内不做任何悬浮球外观/行为代码；本提案大工作区欢迎块处的 100px 圆形位置以中性虚线圆环占位，标注「球体区域 · 现行设计保持不变」。

面板承接：对话面板/工作区仍以球为锚点展开——右缘 +8 优先，放不下时落球左侧；拖动时球 + 面板成组移动的现行算法不动。本方案仅更换面板内部皮肤（切角黑面板、磷光文字、控制台栅格），停靠几何与 placeOrb 判定保持原样，因此 Windows 分数 DPI 的 1×–2× 复测结论仍然有效。

落地建议 Renderer / CSS 宏观位置 · 不含实现代码

1) ui/tokens.css：新增磷光 token 组（凸起/描边/辉光/扫描线四族），声明 data-ph 全局属性开关，不触碰现有 data-glass/data-theme/data-calm 语义。
