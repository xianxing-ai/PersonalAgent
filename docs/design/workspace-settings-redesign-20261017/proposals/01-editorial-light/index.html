    报纸的版面语言比图形界面更早解决「信息过载」：白纸、墨字、细线和编号。晨白 · 编辑部把大工作区当成一期期刊来排——目标总览是「头条」，任务流排成目录条，审批是贴在版边的便笺，证据词汇像刊名一样小写保留。它只做三件决定：其一，全页仅一道国际蓝 #1f4ed8，其余交给墨与纸，让状态词成为唯一允许的色彩事件；其二，取消全部阴影与玻璃，分层交给 1px 阴线、dotted 引线与两层留白，hover 只允许一层微弱纸灰；其三，悬浮球区域原样封存。衬线标题负责气质，Segoe 负责德性——让阅读密集的中文案卷先舒服，再谈好看。

    120mshover 底色、开关滑块（一次性状态变化）

    320ms抽屉开合（位移大，多 120ms 余量）

    S·5

    无障碍

    ACCESSIBILITY
    对比度墨黑/纸白 17.5:1；灰目正文 5.1:1；国际蓝文字 6.3:1；蓝底白字 6.7:1 —— 均达 AA，正文达 AAA。
    focus 可见性:focus-visible = 2px 国际蓝描边 + 2px offset；开关、分段、滑杆均由真实 button / input 承载，键盘可达。
    reduced-motion媒体查询与「降低动效」双通道降级：动画停、过渡 ≤0，2s tick 停止，快照时间保持静态。
    语义状态用 role=status 的 toast 与 aria-live 播报；chip 用 aria-pressed；开关用 role=switch + aria-checked；抽屉 role=dialog + Esc 关闭。

    参考体系与借鉴点

    REFERENCES
    • Untitled UI（浅色编辑排版传统）——借鉴其「eyebrow 小标签 + 大标题 + 细线分节」的层级骨架与克制的强调色法则。
    • Vercel Geist——借鉴其黑白极简下的 hairline 阴线体系与直角容器；色板收敛到「纸、墨、一道蓝」。
    • IBM Carbon 密度哲学——借鉴其网格规约与目录式高密度列表（本稿任务流/设置条目的对齐方式）。
    • 中文报纸版式（宋体标题 / 码号页码）——借鉴衬线大标题、编号与 dotted 引线的期刊目录手法。

    借鉴仅限排版语法与 token 策略；业务功能与信息架构以盘点金标准为准，不做增删。

    C·1

    对比现行「墨核」玻璃方案

    VS. INK-CORE GLASS
    维度现行墨核（冷光青玻璃）晨白 · 编辑部
    明暗深色为主：bg #0b0d10 / #0e1116；admin/workspace 实心表面；另有一层历史黑白纯面覆盖并存。纸白 #FAF9F6 暖白全天候；墨黑 #141414 正文，对比 17.5:1。深色对偶保留为后续工作（不剥夺 data-theme）。
    材质玻璃：blur(42px) saturate(1.8) + 内高光 + 三档阴影；但 admin/workspace 已降级为实心 surface。无玻璃、无阴影：纸面直角卡片，分层靠 1px 阴线 / dotted 引线 / 背景阶；hover 仅一层 #F1EEE6 纸灰。
    色板焦点冷光青 accent #52c7bd（hover #6bd6cd）+ success/warn/danger/info 四语义；主题另有 amber/vermilion/lime 变体。单一国际蓝 #1f4ed8 贯穿链接、选中态、进度条与 focus ring；语义色只染色「状态词」，不参与版式结构。
    字体Segoe UI Variable Text + 雅黑全责；标题 600、−0.01em；数字 Cascadia Mono。衬线栈（Georgia / 思源宋体 / 宋体）承担报头与章节标题；正文控件仍 Segoe UI Variable Text + 雅黑；页码与期号 Cascadia Mono。
    密度中密度；卡片圆角 14–18px；workspace 断点 960/900/720/640 降密。目录式高读密度：期刊条目行 1px 阴线分隔、无卡片框；卡片页反而更大留白（severe 留白）。
    导航形态左侧 196/228px 导航 + admin 搜索；workspace 顶栏工具按钮。报头 + 目录式双栏：左「期刊目」编号 00–06（工作区）/ P·01–29（设置），右正文栏；设置页同构，搜索框在目录头。
    交互中心对话面板 composer 与球体为中心，workspace 是扩展视图。版面成为工作台：任务条目 + 审批便笺是主角；球体区域原样占位声明，composer 仍保留现行文案。
    动效基调80/150/240/400ms + cubic-bezier(.2,0,0,1)；data-calm 降级（动画停、过渡 ≤150ms）。同一缓动家族，时长收敛 120/200/320ms；prefers-reduced-motion 与「降低动效」双通道即停，2s 实时 tick 一并停用。
    桌面协同一次 desktop:update 广播四窗；F8/F9/Ctrl+Shift+Space 设备级绑定；语言经词典中英对照。不改窗口形态、IPC、绑定与词典机制；把新增文案按「中文为主 + 英文词典词条」整理进 desktop-shell 词典。
    风险与取舍玻璃在低配/高分屏的性能损耗；「冷光青玻璃 vs 黑白纯面」两套叙事并存造成 admin 观感漂移。代价：失去毛玻璃情绪质感；衬线小字在 1× 低分屏发虚、纸白夜间偏亮 —— 需要保留深色对偶与 1.25×+ 缩放复测。

    两套主题叙事的裁决：本稿建议以「纸面编辑部」统一黑白纯面叙事，把玻璃叙事收敛到 panel/orb 等悬浮窗口；tokens.css 的 data-theme / data-glass / data-calm 约定全部保留。

    C·2

    悬浮球承接说明

    ORB · UNCHANGED

    球体不动。canvas 粒子球、呼吸动画、112×112 固定窗口、右下默认位、hover ≤90px 触发展开（主进程 placeOrb 计算）全部保持现行设计。本稿在欢迎块以 100px 中性占位环注明「球体区域 · 现行设计保持不变」，不提供任何替换视觉。

    面板以球为锚点展开：420×640 对话面板仍停靠球旁（右缘 +8 优先，放不下落左侧），拖动时球与面板成组。晨白在此只做纸面皮肤：面板成为一页「白纸便签」——报头一行状态词、正文字流、admin 以 anchor 锚定后第一章即「今日任务流」，面板与工作区的 t 区块编号一致（互为页码引用）。停靠方向、断点与分数 DPI（1×–2×）行为按 placement.js 不变，仅换肤不改锚定。

    落地建议

    ROLL-OUT NOTES

    Renderer/CSS 宏观位置（只谈位置，不写实现代码）：

    其一，tokens.css：以纸白/墨黑/国际蓝为默认值注入浅色套，深色对偶挂 data-theme="dark" 条件下继续使用现行墨核值；data-glass 在 workspace/admin 上置为实体，panel/orb 保留玻璃变量。其二，style.css / surfaces.css：把按卡片圆角与阴影的规则收敛到「hairline + 背景阶」两个 mixin 位；按钮、chip、开关与表格在大工作区与 admin 两处共享一套新基类。其三，features/admin/view.js 与 desktop-settings 三件套：导航结构不动，仅替换类名层与文案词典；新增文案补齐中英对照后按一次 desktop:update 广播全窗口。其四，控件矩阵与断言：switch/segmented/range 的渲染签名与防重复提交断言需在提案落地时登记新结构签名（一按钮一 IPC 语义不变）。其五，字迹验证：宋体栈在 1× 低分屏 + 90% 字体缩放的组合要做一次人工复测，必要时回退到思源宋体优先。
