聚焦规则：Tab 到任意控件时，下边线以 scaleX(0→1) 进场（fields），按钮/链接触发 2px accent outline。

无障碍

  • 对比度：正文 #1A1A1A / canvas ≈ 17.4:1；次要 #424242 ≈ 9.7:1；说明 #616161 ≈ 6.2:1；accent 白字 ≈ 6.3:1（AA），均高于 4.5:1 阈值。
  • focus 可见性：全部可交互元素用真实 button / a / input / [tabindex]；:focus-visible 给 2px accent 描边，输入类附加 2px 底线进场。
  • switch / checkbox 均为 button[role][aria-checked]；Tab 条用 role=tablist/tab；抽屉与对话框为 role=dialog，Esc 关闭并归还焦点。
  • prefers-reduced-motion 时：进度模拟 ticker 不启动，所有动画与过渡停用（CSS 强制）。
  • 非文本图标一律 aria-hidden 或配 aria-label；toast 用 role=status（aria-live=polite）。

设计理念

「仲夏 · Fluent」把 PersonalAgent 当作 Windows 11 的一块原生面板来设计：底面铺 Mica 浅灰蓝，工作面沉白，两组之间只用一根 6% 黑的 hairline 分隔。信息架构上，大工作区借「任务管理器」的命令条 + Tab + dataGrid 骨架承载任务流，借「设置」的卡片行语法承载目标、审批与证据；审批以「通知中心」的白色 flyout 卡进 pane，让「批准并继续」像即时的系统授权一样直接。控件全部是 Fluent 原生尺度：39×20 方滑块 switch、20px 方框 checkbox、下箭头 dropdown、下边线 tab 指示器，focus 有清晰的 2px 底线进场。Reveal 高光以 150px 径向 highlight 跟随指针，把白面卡片的 hover 反馈交代出来。浅色同样严肃：primary/secondary/subtle 三层按钮、语义色五档、字阶到 28px 标题，让任务密集的数据密度与 Windows 桌面并置时不突兀，也不喧哗。

参考体系与借鉴点

  • Microsoft Fluent 2 Web：token 命名与字阶（caption12/body14/subtitle20/title28）；「输入类控件 focus 底线」与 segmented/busy 指示。
  • Windows 11 设置应用：面包屑 28px 标题 + 卡片行（label + 右控件 + 12px 灰说明）+ 左侧列表导航 + 顶部圆角搜索框的整页语法。
  • Windows 11 任务管理器：命令条 + Tab + 高密度 dataGrid 的「监控塔」交互中心，与聊天/目标双模板混合。
  • Windows 通知中心：审批卡的白底 flyout 条形与「批准并继续 / 拒绝」按钮排布。
  • WinUI 3 控件规范：switch 39×20 方滑块与 expand-on-check 动效、checkbox 对勾、flyout 6px 圆角。
  • Mica / Acrylic 材质：底面壁纸 tint 通过 CSS 渐变近似；侧栏以 backdrop-filter blur+saturate 复现 acrylic。

悬浮球承接说明

球体完全不动：canvas 粒子球、呼吸动效、112×112 逻辑尺寸、右下固定、hover ≤90px 触发展开判定均为现行设计。本方案仅涉及面板层——panel（420×640）仍以球为锚点展开：优先停在右缘 +8px；屏幕右侧放不下时换到球体左侧；拖动时球与面板成组、结束后应用「贴边吸附」；Esc 收起面板。建议：本提案欢迎块中的 100px 球占位、设置页 ORB-02 行、桌面设置「靠近悬浮球展开面板」开关均为「保持现状」标注，不做任何球面外观或动画再设计。
