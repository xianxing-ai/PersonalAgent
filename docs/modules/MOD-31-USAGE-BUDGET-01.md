# MOD-31/32 用量上限

Competition Profile 的本机用量账本。估算费用不是供应商账单，接口未冻结。

- 账本只追加，保存在既有加密模块文件 `usage-budget.json`。重启后继续累加，不改历史条目。
- 每日、每月上限按估算元计算，同时计入模型 token 和云端调用时长。留空表示不限制。
- 达到 80% 时经桌面通知端口 `sendAdvisoryNotification` 发一条通知。端口尚未绑定时使用同一 Electron `Notification`。
- 超限动作为降级时，新的执行模型和本地模型网关改用更便宜的已公布模型。动作为暂停时，持续工作流和已标记的主动云调用不再发出；用户手动提交的任务仍执行，并在用量行和通知里提示。
- 设置经现有 preload `desktop.invoke` → `desktop:action`。页面只有每日上限、每月上限、超限处理和一行当前用量。
