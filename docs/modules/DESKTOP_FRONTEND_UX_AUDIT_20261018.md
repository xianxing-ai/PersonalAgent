## 已复现的问题及本轮修复

| 问题 | 复现与影响 | 修复与验收 |
| --- | --- | --- |
| 任务详情自动折叠 | 原生点击打开详情后，重放 10 次完全相同的后台快照；`#content` 被替换 10 次，展开数从 1 变 0。用户容易误以为按钮没有点上 | 无关快照保留原 DOM；真正任务更新时按任务 ID 恢复手动展开/折叠及 summary 焦点 |
| 模型设置重复绑定事件 | 旧代码保留 models DOM，却在每次 render 后重新 addEventListener；同一按钮会积累多个处理器 | 保留节点时不重复绑定。十次刷新后单击“测试”只产生一次 IPC |
| 模型开关失败不能回滚 | Local/Fake 旧模型页的异步 catch 使用事件派发后已失效的 currentTarget | 在 await 前捕获控件与旧值；离线拒绝后恢复开关并显示错误。不冒充 Competition 原生模型设置缺陷 |
| 连接器与详情互相遮挡 | 详情打开时 CSS 隐藏连接器，但连接器按钮独立切换 hidden/aria-expanded，可能显示已展开却不可见 | 一个状态同步两侧栏；点连接器会退出详情。关闭详情恢复原先连接器显示偏好；任务消失或切换会话不会保留旧详情 |
| 隐藏详情后焦点遗失 | 关闭按钮随详情隐藏，键盘用户失去操作位置 | 返回对应任务“查看”按钮；任务已消失时返回连接器按钮 |
| 预算拖动重复持久化 | Panel 与旧模型页在每个 input 档位保存并广播偏好；Panel 拖动中还可能被快照覆盖 | input 只即时更新标签；change 提交最终值。保留新拖动意图、错误恢复及会话隔离。该范围只有 0～5 六档，不声称每像素写入或已测出严重掉帧 |
| 设置搜索难发现功能 | 仅匹配菜单标题，搜索 API/日历/证据找不到对应入口；零结果只有空白导航 | 增加常见能力别名、结果数量、零结果提示、Escape 清空、向下键进入结果；保留 22 个入口 |
| 搜索输入点击区域偏小、任务记录难扫读 | 文本输入区域高度较小；记录以内部任务 ID 为主 | 搜索输入最小高度 32 CSS px；任务以已有用户消息作标题，ID 次级显示，状态使用文字与标记。没有消息时仍显示原 ID |

## 与成熟智能体产品的体验差距及改进顺序

这是体验判断，不是模型能力排名。当前页面偏设置管理台：22 个菜单入口、较多状态说明与技术术语，日常对话、任务、开发配置和成果的主次不够清晰。

| 优先级 | 具体改进 | 验收条件与约束 |
| --- | --- | --- |
| P1 主任务入口 | 对话/任务/成果作为日常入口；高级配置收进设置分组，保留所有现有路线与搜索 | 首次使用者能找到“开始任务、正在执行、查看成果”；同一区域一个明显主操作；空态给出真实下一步 |
| P1 任务进展 | 展示当前步骤、等待谁处理、最近事件、停止反馈；详情按需展开 | 直接消费 Runtime 状态，区分受理、执行中、等待审批、待核实、完成；不制造假进度百分比，不让后台刷新打断输入 |
| P1 操作反馈 | 按钮即时 busy/禁用、防重复点击；失败在原位置说明并提供显式重试 | 按钮状态能反映真实请求；关键状态变化可被读屏感知且不偷焦点；采样输入至下一绘制反馈后再评估卡顿 |
| P2 成果工作区 | 文件、代码、报告或网页使用独立预览区，能返回相关对话与版本 | 只展示可信执行链实际交付的对象；先接现有产物，不虚构后端下载/版本接口 |
| P2 变更审阅 | 涉及文件更改时先展示作用范围、diff、测试结果，再交付或审批 | 复用已有 Policy、Evidence、补丁核实；“停止”不宣称撤销已发生的外部写入 |
| P2 视觉系统 | 收敛排版层级、卡片留白、按钮尺寸、图标说明和空态；减少默认常驻技术说明 | 明暗主题、长文本、键盘焦点、缩放均可用；先截图比对，再替换共享样式，避免一次全站重绘 |
| P3 性能基线 | 为导航、开关、展开和输入各建立可复现采样；大任务列表再评估增量更新/虚拟化 | 记录场景、设备、样本量、长任务及分位数；只有测量证明必要时才引入复杂度 |

参考的公开设计模式：

- [Fluent Button usage](https://fluent2.microsoft.design/components/web/react/core/button/usage)：主次动作层级。
- [WCAG 状态消息](https://www.w3.org/WAI/WCAG22/Understanding/status-messages.html)、[Disclosure 键盘与展开语义](https://www.w3.org/WAI/ARIA/apg/patterns/disclosure/)：反馈可感知、展开状态一致。
- [Claude Artifacts](https://support.claude.com/en/articles/17153992-what-are-artifacts-and-how-do-i-use-them)：成果作为可独立查看的工作对象。
- [Cursor Reviewing and testing](https://cursor.com/learn/reviewing-testing)：变更的审阅与验证入口。
- [INP](https://web.dev/articles/inp)：交互性能的度量方式；200ms 是该指标的良好阈值，不是模型回答时限。

上述大型设计建议尚未实现。本轮不增加第二套任务状态、执行循环、授权体系或未经公布的产物契约。
