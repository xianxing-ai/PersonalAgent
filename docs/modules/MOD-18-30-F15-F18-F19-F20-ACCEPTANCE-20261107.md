### 1.3 F18 / F19 PR 评审合并与 Issue 分诊修复图路径及 60 秒超时收敛（MOD-30）

   - **根因**：F15 子任务修复本身仅需约 `2.4s`，主要耗时位于 `F19_N03`（`f19-publication-host.js` -> `git-tools.ts`）三阶段发布（`commit`、`push`、`pr.create`）及每次动作前后的 `readPublicationPreview`，在 Windows 下顺序拉起 140+ 次 `git.exe` 子进程并叠加 SQLite FULL-sync 落盘与 F15 双轮重试，使单次全图测试耗时约 `55s–67s`，触碰旧版 60s 默认超时。
