## 本包范围

#372 的产品烟测把固定合成 HTTPS 地址映射到 loopback HTTP，不能证明默认传输的 TLS 证书校验。本包只新增独立验证入口、扩展既有测试夹具的可选 HTTPS 模式并同步文档；不修改生产 Host、Runtime、UI、Policy、wire/contracts Schema、数据库迁移、依赖或锁文件。

OpenSSL 在独立项目缓存生成一天有效的合成自签名证书，服务仅监听 127.0.0.1；worker 通过自身 `NODE_EXTRA_CA_CERTS` 信任测试证书，使用原 SDK 和生产默认 fetch，没有 fetch adapter、URL 改写、系统信任库写入或关闭证书验证。派生进程环境只保留必要平台字段，不继承真实账号/云凭据/代理/Node 选项。测试证书/私钥不会进入 Git。

原生确认是合成回调，worker 的配置安全存储是显式 Fake；不替代 #372 的实际 Electron safeStorage/窗口证据。运行原 SQLite Runtime、Policy/ToolGateway 和 `authorization.respond`，证据等级仍为 conditional。
