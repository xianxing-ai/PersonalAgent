# 接线责任与华为优先验收

日期：2026-10-17。适用 `huawei_ict_agentarts`，覆盖所有模块负责人及受委派的前端/CLI 执行者；长期模块归属仍以 [MODULE_ASSIGNMENTS](../MODULE_ASSIGNMENTS.md) 和 Owner 的明确交接为准。

## 自己接线、自己测试、本人确认

每位负责人交付：实现 → 公开接口 → 生产注册/实际调用方 → 自己运行必要测试 → 实际结果/Evidence → 文档及 PR。根集成人提供共享边界协调，不默认代接、代测或集中承担所有真实验收。共享文件由本工作包协调后补齐所需接线。

所有负责人在本人工作包/PR 回复下列确认。确认职责不等于确认完成；不得替其他人填写“已确认”、虚构回执或把未回复视为同意。采用 CLI/开发 Agent 协助时，模块负责人保留完整交付责任，并记录实际执行者。

```text
本人 / 工作包 / 模块：
我确认：由本工作包完成生产调用方接线、必要测试及证据交付。
源码 SHA / 公开接口版本 / 生产注册及调用方文件：
已完成接线 / 未完成接线 / 精确依赖与交接人：
华为评测集及版本 / 评估任务 / 指定镜像与运行时版本：
实际执行结果与 Evidence（未运行填写 not_run；不可确定填写 unknown）：
若改用本地：平台不可用依据 / 本地验证范围 / 平台复测条件：
```

这项本人职责确认适用于所有交付者，不改变当前有效的 PR 独立评审和合并规则；不要求每个日常 PR 由所有人逐一批准。

## 镜像和工作流先在华为评估

1. **先准备平台用例。** 将本工作包的固定输入、预期结果、必要上下文和成功/失败用例放入 AgentArts 评测集，并提交可引用的版本。平台提供评测集管理与评估器，项目专属用例仍需负责人准备；不假定平台自带覆盖全部功能的考卷。
2. **对准实际生产版本执行。** 通过当前可用的高代码运行时评估入口或受控 runner 调用指定镜像/运行时版本，驱动原生产入口。涉及本机 Laya、工具和设备时使用原可信桥接及 Policy/ToolGateway；评估任务不能绕过这些依赖。
3. **完成整条图再评价。** 对工作流逐节点推进到正确终态，保存实际工具回执、产物/校验结果、主路径与影子隔离结果以及重要阶段耗时；把真实输出或真实 Trace 交平台支持的评估流程，保留评估任务和报告标识。仅对历史结果评分要写明“未重新执行镜像”，不能冒充本次运行。
4. **本地替代放在有据可查的平台阻碍之后。** 平台不可用或不支持本场景时，记录具体入口、UTC 时间、错误/能力依据、影响范围及恢复条件，再采用本地同版镜像或真实宿主测试。能力明确不支持时保留官方依据即可，不要求反复发起必然失败的请求。不可用项保持未验；生产服务不得因此静默切换 Local Profile。

本地替代须保留相同输入、验收标准及版本绑定，说明与目标云环境的差异。缺少平台消费适配本身也是待办：负责人继续完成可独立实现的接线并交接缺项，不能长期仅以“尚未接平台”为本地验收通过的理由。账号、服务开通、付费或权限不足按已有授权处理，不能通过伪造配置、自动扩大权限或改用 Fake 隐去阻碍。

## 平台评估与必要本地检查的边界

- “华为优先”用于镜像/工作流的业务与效果验收。语法、类型、单元、契约、安全边界及 CI 等必要工程检查继续按改动执行，无须先发起云评估；纯文档 PR 检查链接和 diff 即可。
- 物理麦克风/扬声器、Windows 桌面输入、实体通知和本地凭据恢复需要相应真实设备证据。平台无法直接观察的部分在该设备验证，并记录它在完整云调用链中的关联；不以平台评分代替设备验收。
- 主/影子须绑定输入、基线、配置与版本，隔离真实写入及通知；缺少反事实或运行结果时标 unknown。多阶段与并行耗时分别记录，不相加重叠区间。
- 平台评分、模型自报、接口注册、目录存在、编译和 Fake 通过均不能代替生产调用回执、文件/测试读回或整图终态。保留失败原始记录，不把“任务创建成功”当成“业务测试通过”。
- 代码、接线、工程检查、平台效果、真实账号/设备、PR 合并和发布分别记账。本地通过后仍需平台验收的部分保持未验并列出复测条件，不自动标记整个 MOD 或全部 28 图完成。

## 最小验收证据

每个工作包提供：负责人/执行者、源码 SHA、profile、镜像摘要和精确运行时版本、评测集 ID/版本、评估任务/报告 ID、task/run/request/Trace 关联、实际生产调用方及节点回执、产物/验证摘要、UTC 起止与阶段耗时、失败/unknown/not_run、必要本地验证及平台阻碍证据。字段确实不适用时说明原因；历史、Fake、本机和云端分开，公开材料不含密钥或私人数据。

平台高代码/运行时的具体评估对象、字段映射和可用性由当前区域与账号实际验证；不能把低代码智能体在线评估的支持范围直接套到自有运行时。
