## 行为与兼容

默认桌面对话继续由 AgentArts 云模型规划，保留自定义模型入口。原普通任务续接保留实际工具目录，原需要派遣的主任务保持其汇总边界，子任务使用原 Runtime／Policy／ToolGateway／Evidence 执行。没有额外任务库或另一套执行循环。

可信宿主为默认新任务启用渐进执行，起始窗口 32 步；默认派遣的 `user-work` 继承它。已冻结的团队计划保留成员原初始步数，例如 coder 的 6 步，同时继承来源的渐进窗口、显式总上限和原期限，不能将成员初始步数当成项目总上限。思考深度和 Fast 不再覆盖默认任务的执行容量。`PA_AGENTARTS_EXECUTION_WINDOW_STEPS`、`PA_AGENTARTS_EXECUTION_MAX_STEPS` 和 `PA_AGENTARTS_TASK_TIMEOUT_MS` 是宿主配置；未配置显式总步数时不添加项目总步数上限。默认任务期限 30 分钟，支持宿主配置；受理后不改写该任务期限。旧任务、旧审批和原持久预算不自动扩大。

续窗依据是原 Runtime 已确认、原授权允许且输入绑定匹配的执行记录及原结果。不同输入的确认进展可以继续，同一输入换提案号不能无限续窗；未核实写入、未知云请求、取消和超期不能通过续窗绕过。子任务与子会话的新轮沿原来源继承该策略，保留原终态和历史。

工具多于每次 64 项或 Schema 超过 24 KiB 时，经 `capability.search` 检索原任务初始可用集合。只有原确认回执才激活下一轮的精确工具页，游标和 Schema 不得跨任务替换。工具页变更后仍校验 readiness 和原 Policy；完整目录不做静默截断。`computer.request_access` 的成功状态与后续工具授权分开说明，避免将 `authorizationGranted:false` 误读成访问失败并反复申请。

连续出机保留当前及至多 32 条近期回执，并按完整 JSON 请求的 1,100,000 字节门槛进一步缩窗。原 Runtime 全量结果、ExecutionRecord、Evidence 和检查点完整保留；元数据披露省略数量，必要文件及状态经原工具重读。计数、摘要和模型自报不证明用户目标完成。
