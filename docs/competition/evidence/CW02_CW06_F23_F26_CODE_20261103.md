## 本地执行回执状态修复

精确版本只读关联此前只检查本地 `evidenceId`，会把失败、未知或缺少状态的回执也记为 `localExecuted: true`。现在要求执行端口明确返回 `state: succeeded`；其他状态返回 `RESULT_UNKNOWN`，不重复云提案或本地调用，也不写成功关联记录。
