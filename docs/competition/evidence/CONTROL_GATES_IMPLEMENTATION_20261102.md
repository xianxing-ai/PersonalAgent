# #533 控制权设计的生产接线

目标为 `huawei_ict_agentarts`；实现分支 `codex/control-gates-implementation`，工作树 `.worktrees/control-gates-implementation`，依赖 #531 的已有工作流。#533 本身是已合并的设计文档 PR，本记录对应后续代码，不能把设计合并当作实现验收。

## 调用链与边界

- Desktop 侧栏显式维护本对话禁止项，沿现有会话存储与 CAS 保存。普通聊天不产生规则。Runtime Application 在询问前、ToolGateway 实际执行前读取当前规则；按动作类别阻止，对象或类别不明时拒绝。规则原句、否定、期限、条件和未决确认保留，不交给模型摘要；桌面历史覆盖不会丢失原任务的未完成状态。
- 原授权卡展示发信、发布、删除等操作的完整目标和内容，继续绑定原参数摘要；内容确认只能逐次批准，完全访问、任务授权和长期授权不能代答。F23 N04 发布配置同样经过内容确认，已有任务继续读原固定版本。
- F16/F19 使用原受限 Git 读取器构造完整差异，预览和提交复用原受信字节生成同一 tree；提交和推送前再次检查已确认 tree、指纹和原授权。不截断差异，不用模型描述代替正文；既有 Git 不支持的新文件、删除路径及超限差异仍明确不可用。
- F02 读取同一图中已确认的 N03 最终语音回执，核对问题、修订和原操作参数，再由原确认/拒绝 host 写入 `allow_once` / `deny`。确定性匹配整句同意或拒绝；条件句、歧义、替换参数、失效 final 均不能放行。只读 guard 不写授权。
- Runtime 用原 SQLite 检查点保存执行世代，停止、暂停、重规划先在本地递增，再通知云端；原未知副作用记录保留。工具最终执行前核对自身与所属图的固定世代，旧图不能通过重新恢复或重用提案 ID 获得新世代。
- AgentArts、ModelGateway、持续工作流、图像与 SIS 出机入口由可信宿主检查实际目的地和正文。密钥和可识别个人信息拒绝发送；未知内容本地分类，其他隐私另问本次同意。目的地、正文、取消范围、来源或期限变化后不能沿用批准。WSS 转 HTTPS 单独核对实际目的地。当前没有可信本地图像/原音频分类器，因此生产原始图像与音频上传返回不支持，不把文字弹窗当作图片或声音审核。
- 冻结轨迹按历史顺序逐步比较，首次工具或参数分叉后全部保留未知；写操作只比较提案，不实际执行。报告固定标注 `single_step`，不声称整图成功。
- 不可恢复的通用删除明确拒绝。已有记忆、事实、学习记录的彻底删除先保存待决对象和版本；同一对话实际新增用户回合后，再经原生确认执行。重复点击不算下一回合，已开始而结果未知的删除不重放。未新增回收站或 Git 删除 capability。
- 失败/未知写入及已记录的云端完成、本地必需子任务未完成冲突，沿原任务展示待决操作。邮箱已有只读对账口最多核实一次，其他来源明确 unavailable；不调用 apply/resume，不改原终态。用户跳过绑定此冲突摘要和当前任务修订。当前未配置固定联系邮箱，明确记录 notification_skipped，不能冒充已通知。

## 兼容性

没有新增数据库、调度器、权限系统、依赖或已发布迁移。世代、对话规则和决定复用原持久存储。公共接口继续为 provisional。

普通 AgentArts 传输增加版本化宿主包 `{executionEpochVersion:1, executionEpoch, query}`，镜像只解包原业务输入并在结果外回显同一世代；模型不能选择回显值。旧镜像缺少包回显时拒绝，不能继续当作新设计已生效。F02 N05 的真实授权写入使 host effect 改为 write，模板摘要随之变化，旧图/镜像须重新绑定。

Owned 与主动工作流的 advance 同样绑定宿主固定世代；只读能力目录 describe 不产生可执行提案。已有传输测试的假镜像通过 `tests/helpers/synthetic-agentarts.mjs` 显式解包并回显原请求世代，不补造真实回执。旧世代、缺字段、非法结果测试保留原拒绝条件。
