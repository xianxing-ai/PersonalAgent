## 官方支持与本项目适用性

2026-10-13 重新读取华为[模型优化概述](https://support.huaweicloud.com/ops-agentarts/agentarts_14_0094.html)
（页面标注更新 2026-09-17）。其描述的是面向具体任务的强化学习优化：
单 Agent 不能包含工作流，插件和 MCP 分别最多 5 个；工作流目标模型节点的前置路径不能有等待用户输入的节点，
目标模型节点不能处于循环中。文档同时说明应有清晰任务边界、可评奖励和有效数据，不据此保证效果。

**本项目的研究判断：** 镜像内 JavaScript 实现的 World / Plan / Review 与平台可选择的优化对象不能直接划等号。
现有 8 Workflow / 3 Controller 绑定目录，只证明应用公开了这些入口；它没有提供平台模型优化对象 ID、
训练配置或基础模型白名单。因此不声称当前 owned Runtime 可以直接一键训练，也不声称平台确定不支持；
需先取得当前账号/区域实际可选对象及模型的读回。

[MaaS 对话 API](https://support.huaweicloud.com/model-call-maas/model-call-021.html)
公布了推理参数与模型相关限制；调用权限不自动包含训练权限。当前真实记录使用 DeepSeek，
不能将 `PanguModelProvider` 类型、盘古产品名称或文档中的模型列表当成项目已验证盘古或盘古训练的依据。

## 可复用实验与其限度

依据 [2026-10-12 真实镜像验收](../../modules/AGENTARTS-HUAWEI-LIVE-COMPATIBILITY-20261012.md)：

- 一条真实 WSS → MaaS → 本地一次性授权 → 生产文件读取 → Evidence → 云端续答通过，任务 succeeded。
  测试文件为公开合成内容，仅执行一次读取，不能估计跨场景成功率。
- 独立 MaaS 参数诊断曾因 `reasoning_effort:none` 返回 400；适配为该模型支持的 thinking 控制后返回 200。
  这证明参数兼容修复，不是训练效果；两次诊断的输出 token 差异也不是受控成本比较。
- 绑定发现读回 8 Workflow / 3 Controller，不等于训练样本，更不等于所有入口已经逐项真实执行。
- [现有离线评分材料](../../../tests/manual/agentarts/evaluation/MVP-PLATFORM-EVALUATION-20260930.md)
  可参考其可重复输入和评分方法；没有实际平台任务和结果时仍是离线协议证据。

## 无需新训练即可完成的研究准备

以下是后续实验方案，并非已有实验结果。本轮已完成方案和证据条件定义，不上传任何数据。

| 研究项 | 可审交付 | 通过判断 |
| --- | --- | --- |
| 区分模型错误与工程错误 | 按认证、路由、协议、模型输出、授权、执行读回分类失败 | 不能把 401/路径错误、缺配置、来源拒绝归类为“模型需微调” |
| 最小修复样本设计 | 有来源的前后事实、原图版本、允许目标、应保持不变的节点、预期 KEEP/RECHECK/REVISE | 预期由确定性规则和独立人工核对；模型报告不自己充当标签 |
| 数据来源登记 | 每项记录授权用途、来源与版本、是否可出机、脱敏过程、删除机制 | 私人代码、对话、邮件、Wiki、原始工具结果不自动成为训练集 |
| 训练/验证/测试拆分方案 | 按项目、来源及时间分组；同一案例改写与同一目标的连续修订留在同组 | 防止模板、来源或历史泄漏到测试集；合成数据与真实授权数据分开统计 |
| 不训练的基线 | 固定当前镜像、提示版本、模型、输入和工具目录，与确定性路由分别对照 | 先记录失败及不确定结果，不丢弃失败样本、不暗中重试或切换供应商 |
| 改动后的独立评估 | 同一冻结测试集对照；报告样本数、覆盖类别、失败分布和不确定性 | 不只比较训练奖励、格式通过或一个成功例子 |

指标应覆盖：报告/候选有效率、引用来源正确率、无关节点保持率、所需改动遗漏率、
缺少证据时的 RECHECK、越权提案比例、本地实际任务完成率、每个逻辑任务的模型调用次数、
可读回 token 与端到端时延。删除/新增节点等当前契约不支持的动作单列，不评分为已实现。
云端得分不能替代本地 Policy、CAS 或执行 Evidence；安全硬约束仍由代码保持。
样本量与判断门槛须按真实任务分布及统计目标确定，本文不临时指定固定数量、训练预算或费用上限。
